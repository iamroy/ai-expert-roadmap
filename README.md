# AI Expert — 12-Month Roadmap

A private, evolving collection of learning materials, exercises, projects, and progress notes for becoming an AI systems expert.

The program starts with **Month 0**, a short prerequisite review. The numbered 12-month roadmap begins after the prerequisite checkpoint.

## Learning approach

- **SKIM** — review briefly, validate understanding, and move on.
- **LEARN** — understand well enough to design, implement, and debug production systems.
- **MASTER** — understand the theory, implement it, benchmark alternatives, and defend design tradeoffs.

Each month will contain:

- learning objectives and topic checklists
- concise lessons and selected references
- hands-on exercises
- a month project
- knowledge checks and exit criteria
- progress notes

## Repository conventions

- Keep one directory per month.
- Record progress in each month's `progress.md`.
- Store runnable work under the month's `exercises/` or `project/` directory.
- Prefer primary documentation and papers over framework-specific tutorials.
- Never store API keys, credentials, private datasets, or large model artifacts in Git.
